# awesome-ui

A React component library styled with Tailwind CSS v4 in Flowbite's design language.

Use the **Theme** and **Mode** controls in the toolbar to switch between the three built-in
themes (`flowbite`, `slate-pro`, `soft`) in light and dark mode.

Components land phase by phase. See `PROGRESS.md` in the repository for status.
